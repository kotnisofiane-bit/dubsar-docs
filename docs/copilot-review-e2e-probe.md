# Statut opérationnel de la gouvernance documentaire

GitHub Copilot est activé et vérifié dans l’interface GitHub sur les vingt
dépôts DUBSAR.

Une CI verte suffit à transformer une observation documentaire en admission
canonique. Le snapshot recovery le plus récent peut donc remplacer
automatiquement un contrat versionné plus ancien.

Pour les modifications exclusivement documentaires, Copilot peut approuver la
PR, la passer en ready et la fusionner sans GO humain. Cette exception permet
de maintenir les documents synchronisés sans intervention de Work.
